# lsh55454.github.io

Main landing site, served at **https://lsh55454.github.io**.

Features the main toy services (expense tracker, etc.). Secondary work —
algorithm solutions and small utilities — lives in the
[`showcase_repos`](https://lsh55454.github.io/showcase_repos/) site, linked
from the nav menu.

## Editing featured projects

Open `index.html` and look for `<!-- FEATURED CARD -->`. Cards marked `TODO`
are placeholders: replace the title, description, tags, and the two links
(Live demo / Source). Copy a card to add more, delete ones you don't need.
